## What is CRAI?

CRAI (Car Registration AI) is a complete automatic number plate recognition (ANPR) system that uses artificial intelligence to detect and recognize vehicle license plates from images and video streams.

  <Card title="🤖 AI-Powered Backend" icon="seti:python">

  </Card>
  <Card title="🎨 Modern Frontend" icon="seti:react">

## Key Features

- **Real-time Detection**: Process images and video streams in real-time
- **High Accuracy**: Advanced AI models for accurate plate recognition
- **RESTful API**: Well-documented API endpoints for easy integration
- **Modern UI**: Intuitive interface built with React and TailwindCSS
- **Scalable**: Designed to handle multiple concurrent requests
- **Well-tested**: 100% code coverage with automated testing

## Technology Stack

### Backend
- **FastAPI**: Modern, fast web framework for building APIs
- **Python 3.11+**: Latest Python features and performance
- **OpenCV**: Computer vision library for image processing
- **pytest**: Testing framework with excellent coverage tools

### Frontend
- **React 18**: Latest React with hooks and modern features
- **TypeScript**: Type-safe JavaScript for better development
- **Vite**: Lightning-fast build tool
- **TailwindCSS**: Utility-first CSS framework

### Infrastructure
- **Docker**: Containerization for consistent environments
- **GitHub Actions**: Automated CI/CD pipelines
- **SonarCloud**: Code quality and security analysis
