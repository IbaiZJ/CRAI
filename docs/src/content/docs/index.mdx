## What is CRAI?

CRAI (Car Registration AI) is a comprehensive microservices platform that combines automatic number plate recognition (ANPR) with Spanish environmental badge lookup, automation workflows, and real-time data processing capabilities.

## Key Features

- **Real-time ANPR**: Process images and video streams for license plate recognition
- **Environmental Badge Lookup**: Spanish vehicle environmental classification (C, ECO, B, 0) with 4M+ plates
- **Spanish Plate Validation**: Automatic format validation for Spanish license plates (NNNNLLL)
- **Workflow Automation**: Node-RED integration for custom automation scenarios
- **Dataset Management**: Auto-extraction and optimization tools for environmental badge data
- **RESTful APIs**: Well-documented API endpoints for easy integration
- **Modern UI**: Intuitive interface with Firebase authentication
- **Scalable**: Microservices architecture designed to handle multiple concurrent requests
- **Well-tested**: Comprehensive automated testing with CI/CD pipelines

## System Architecture

CRAI consists of 5 independent microservices:

- **Frontend** (Port 6901): React + TypeScript + TailwindCSS interface
- **AI Service** (Port 6902): Python FastAPI for ANPR processing
- **Node-RED** (Port 6903): Workflow automation and orchestration
- **ebAPI Service** (Port 6904): Python FastAPI for environmental badge lookup
- **Documentation** (Port 6910): Astro Starlight documentation site

## Technology Stack

### Backend Services
- **FastAPI**: Modern, fast web framework for building APIs
- **Python 3.11+**: Latest Python features and performance
- **OpenCV**: Computer vision library for ANPR image processing
- **pandas**: Data manipulation for environmental badge dataset
- **py7zr**: Dataset extraction and compression handling
- **pytest**: Backend testing framework with excellent coverage

### Frontend
- **React 19**: Latest React with modern features and hooks
- **TypeScript 5.9**: Type-safe JavaScript for better development
- **Vite 7**: Lightning-fast build tool and dev server
- **TailwindCSS 4**: Utility-first CSS framework
- **React Router 7**: Client-side routing
- **Firebase**: Authentication and user management
- **Vitest 4**: Frontend testing framework with React Testing Library

### Automation & Infrastructure
- **Node-RED**: Visual workflow automation
- **Docker Compose**: Multi-container orchestration
- **GitHub Actions**: Automated CI/CD pipelines
- **Astro 5 + Starlight**: Documentation generation
