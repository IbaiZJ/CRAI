## What is CRAI?

CRAI (Car Registration AI) is a comprehensive microservices platform that combines automatic number plate recognition (ANPR) with Spanish environmental badge lookup, ITV inspection dates, vehicle simulation, automation workflows, and real-time data processing capabilities.

## Key Features

- **Real-time ANPR**: Process live video streams with YOLOv8 vehicle detection and custom license plate detection
- **Multi-Model Detection**: Support for YOLO + OCR and custom SSD detectors
- **Environmental Badge Lookup**: Spanish vehicle environmental classification (0, ECO, C, B, n) with 4M+ plates
- **ITV Date Validation**: Spanish vehicle technical inspection date retrieval
- **Spanish Plate Validation**: Automatic format validation for Spanish license plates (NNNNLLL)
- **Vehicle Simulation**: Traffic simulation with camera and police control management
- **Workflow Automation**: Node-RED integration for custom automation scenarios
- **Modern Dashboard**: User management, statistics, cameras, and vehicle tracking
- **MySQL Integration**: Persistent data storage with Google Cloud SQL support
- **RESTful APIs**: Well-documented API endpoints with Swagger UI
- **Scalable**: Microservices architecture designed to handle multiple concurrent requests
- **Well-tested**: Comprehensive automated testing with GitHub Actions CI/CD and SonarCloud analysis

## System Architecture

CRAI consists of 8 independent services:

| Service | Port | Technology | Description |
|---------|------|------------|-------------|
| **MySQL** | 6900 | MySQL 8 | Persistent database storage |
| **Frontend** | 6901 | React + TypeScript + TailwindCSS | Web dashboard interface |
| **AI Service** | 6902 | Python + YOLOv8 + EasyOCR | Real-time ANPR processing |
| **Node-RED** | 6903 | Node-RED | Workflow automation |
| **ebAPI** | 6904 | FastAPI + Python | Environmental badge lookup |
| **itvAPI** | 6905 | FastAPI + Python | ITV date lookup |
| **OS Service** | 6906 | Spring Boot + Java 17 | Vehicle simulation |
| **Documentation** | 6910 | Astro Starlight | Project documentation |

## Technology Stack

### Backend Services
- **FastAPI**: Modern, fast Python web framework for building APIs
- **Spring Boot 3.2**: Enterprise Java framework for OS service
- **Python 3.11+**: AI processing, badge and ITV lookup services
- **Java 17**: Vehicle simulation service
- **YOLOv8**: Vehicle detection with Ultralytics
- **EasyOCR**: License plate character recognition
- **OpenCV**: Computer vision for image processing
- **TensorFlow/Keras**: Custom SSD vehicle detector
- **pandas**: Data manipulation for datasets
- **pytest & JUnit**: Backend testing frameworks

### Frontend
- **React 19**: Latest React with modern features and hooks
- **TypeScript 5.9**: Type-safe JavaScript for better development
- **Vite 7**: Lightning-fast build tool and dev server
- **TailwindCSS 4**: Utility-first CSS framework
- **React Router 7**: Client-side routing
- **Google OAuth**: Authentication with @react-oauth/google
- **Radix UI**: Accessible component primitives
- **Recharts**: Data visualization
- **Vitest 4**: Frontend testing framework with React Testing Library

### Database & Infrastructure
- **MySQL 8**: Relational database with Cloud SQL support
- **Node-RED**: Visual workflow automation
- **Docker Compose**: Multi-container orchestration
- **GitHub Actions**: Automated CI/CD pipelines
- **SonarCloud**: Code quality analysis
- **Astro 5 + Starlight**: Documentation generation
